# React To-Do App

A minimal To-Do app built with React and Vite. It supports adding tasks, toggling completed, deleting tasks, and saves tasks to localStorage.

## Setup & Run (Windows PowerShell)

Open a PowerShell terminal and run the following commands from the `react-todo` folder:

```powershell
npm install
npm run dev
```

This will start a local development server (Vite) and open a link in the terminal (usually http://localhost:5173) to view the app.

## Build & Preview

```powershell
npm run build
npm run preview
```

## Notes

- This repository includes both original `To-do.html` and the new `react-todo` folder so you can compare the two implementations.
- The app stores data in `localStorage` under the key `react-todo-list`.

Enjoy! 👋
